# Internal
---
## Goals
- Understand MongoDB internal processes and resource usage

## Tasks
* Understand MongoDB memory usage and explain the following configuration:
  * `storage.wiredTiger.engineConfig.cacheSizeGB` (WiredTiger cache size) - how should it be sized relative to the host's total memory? What happens if it's set too high?
  * `net.maxIncomingConnections`
* Read about the `mongod` process and understand:
  * What threads/processes does `mongod` spawn (e.g. the WiredTiger checkpoint thread, TTL monitor)?
  * What is the difference between the WiredTiger cache and the filesystem cache?
* Read about [journaling](https://docs.mongodb.com/manual/core/journaling/) and explain:
  * What does the journal guarantee, and how does it relate to durability?
  * How often does MongoDB write to the journal by default?
  * What happens during crash recovery if the journal is missing or corrupted?
* Read about `currentOp` and `killOp`:
  * How can you list all currently running operations?
  * How can you find and kill a long-running or stuck operation?
* Read about the [database profiler](https://docs.mongodb.com/manual/tutorial/manage-the-database-profiler/):
  * What are the three profiling levels?
  * Where is profiling data stored, and how can you query it for the slowest operations?
  * What is the performance cost of enabling profiling, and how would you limit it in production?
* Read about [`serverStatus`](https://docs.mongodb.com/manual/reference/command/serverStatus/) and explain what information it exposes about connections, memory, and the WiredTiger cache.
