# Security
---
## Goals
- The trainee will understand MongoDB authentication and authorization

## Tasks
* Read about MongoDB authentication and explain:
  * User/Password authentication
  * Read about the `$external` DB and its use case.
  * Read about client certificates, how is it different from server certificates?
  * Read about configuring [X509 Client Authentication](https://www.mongodb.com/docs/v5.0/tutorial/configure-x509-client-authentication/).
  * How does MongoDB authenticate the client's certificate? Which user does the client get access to?
  * How many different users can authenticate using the same certificate?
  * What are the drawbacks of using only the certificate's Common Name?
* Read about [Role-Based Access Control](https://docs.mongodb.com/manual/core/authorization/) and explain:
  * What is the relation between a `User`, a `Role`, and the privileges granted to it?
  * What are some of the built-in roles (e.g. `read`, `readWrite`, `dbAdmin`, `clusterAdmin`)? What is the difference between a database-level and a cluster-level role?
  * How do you create a custom role, and when would you need one instead of a built-in role?
  * Can a role inherit privileges from other roles? Explain how.
  * List all the users and roles defined on your cluster - which commands do you use?
* Do the following task:
  * Create a user with the built-in `read` role on a single database.
  * Create a custom role that can only run a specific subset of commands (e.g. read-only on one collection), and assign it to a new user.
  * Connect as that user and verify they can't perform actions outside their granted privileges.
